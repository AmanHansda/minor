CHRONOS TIMETABLE BUILDER

Administrator workspace for university timetable creation and exports
Administrator Console

1. Enter University Data

Load the sample department, then edit it or add your own classrooms, teachers and class requirements. Save data before generating.

Academic Classes and Student Strength

Create the complete academic class once. There are no sections here. Tutorial allocations automatically split the class into 3 groups and laboratory allocations split it into 2 groups.

Department Classrooms and Laboratories

Enter an existing room number to update its capacity, block, department allocation or room type.

Teachers and Preferences

Unavailable slots are hard rules. Preferred slots improve timetable quality. Enter an existing teacher ID to update their information.

Faculty Teaching Allocation and Weekly Requirements

Student strength is taken automatically from the selected academic class. Full Class Lecture uses the whole group. Tutorial creates 3 equal groups. Laboratory creates 2 equal groups. A lab normally uses a block size of 2 consecutive hours.

2. Generate and Publish

Full Timetable Admin View

Generate a timetable to see all classes.

Teacher Timetable Sheet

This is an administrator preview for checking and exporting a teacher-wise schedule. It is not a teacher login portal.

Class Timetable Sheet

This is an administrator preview for printing or sharing the timetable for an academic class. It is not a student login portal.

Classroom and Laboratory Timetable Sheet

Administrator-only weekly usage view. It confirms that one classroom or laboratory is never allocated to two classes at the same period.
